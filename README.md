# KYC Workflow API

A simple **Node.js + Express** application for handling **KYC applications** and **KYC provider webhooks**.

---

## 🚀 Requirements

- **Node.js** >= 18
- **npm** >= 9 (or yarn / pnpm)

Check versions:
```bash
node -v
npm -v
```

## Installation
git clone https://github.com/trinhdan5555/kyc-workflow.git
cd kyc-workflow

# Install dependencies:
npm install | yarn install

## Running the Application
npm run dev

# Health Check
curl http://localhost:3000/health
```bash
{
  "status": "ok"
}
```
